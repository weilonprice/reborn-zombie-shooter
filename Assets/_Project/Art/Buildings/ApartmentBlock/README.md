# Cedar Court apartment block

Detailed three-storey static exterior: six balconies, boarded windows, entry
canopy, masonry bands, roof terrace, water tank, stairwell and HVAC.
22,552 triangles across eight renderers. UV0 and secondary lightmap UVs, URP
materials and one grounded wall collider. Doors and balconies are decorative.

Ready prefab: Assets/_Project/Prefabs/Buildings/ApartmentBlock.prefab.
Editable source: ArtSource/Buildings/ApartmentBlock/ApartmentBlock.blend.
FBX and GLB included. Rebuild only this asset with:
Blender --background --python ArtSource/Buildings/upgrade_buildings.py -- ApartmentBlock
Then use Tools > Zombie Shooter > Install Detailed Buildings in Unity.
