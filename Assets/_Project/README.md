# Reborn — module map

Unity 6000.6.0f1 · URP · new Input System

Running it, the controls and the architecture that matters live in the
[root README](../../README.md). This file is the layout: what is where, and
which file owns a decision. It deliberately does not repeat the controls table —
there were two of them and one had been wrong for weeks.

## Scripts

| Folder | What it owns |
|---|---|
| `Scripts/Core` | `GameManager` (run state, score), `WaveManager` (spawn table, budget, pooling), `Health` and `IDamageable`, `Hitbox`, `ArenaSelector`, `CameraFollow`, `CameraShake`, `Blast`, the deployables |
| `Scripts/Player` | `PlayerController` (twin-stick locomotion), `InputReader`, `DeployablePlacer` |
| `Scripts/Weapons` | `Weapon` (ammo, rate, crit, ultimate, akimbo), `WeaponVisuals`, `WeaponAnimator`, `PlayerWeaponGrip`, and `Delivery/` |
| `Scripts/Weapons/Delivery` | How a shot travels: hitscan, cone, chain, projectile. A new firing mode is a new asset here, not a branch in `Weapon` |
| `Scripts/Enemies` | `ZombieAI` (steering, reactions, overrides), `FlowField`, and one small component per archetype behaviour |
| `Scripts/Upgrades` | `WeaponUpgradeTree`, `UpgradeManager`, `WeaponStats` |
| `Scripts/UI` | `HUD`, `ArmoryUI`, `UpgradePanel` |
| `Scripts/Editor` | `ArenaBuilder` (owns the whole scene), `AbilityAnimationSetup`, `WeaponGripValidation` |

## Art

`Art/Characters`, `Art/Weapons` and `Art/Buildings` hold FBX exports and their
palette textures. **None of it is hand-modelled** — every model is generated by a
Python script in [`ArtSource/`](../../ArtSource), and the `.blend` files there are
outputs of those scripts rather than sources. Editing a model means editing its
script and re-running Blender headless.

## Design notes

- **The horde is flow-field pathed, not steered.** `FlowField` sweeps a 90×90
  grid outward from the player once and every enemy reads the cell it stands in.
  This replaced straight-line steering, which walked the horde into walls the
  moment the arenas gained interior geometry. Barricades are stamped expensive
  rather than impassable, so a short wall is a detour and a long one is a door.
- **Input is polled directly** from `Keyboard`/`Mouse`/`Gamepad` in `InputReader`
  rather than bound to an `.inputactions` asset, so nothing needs inspector
  wiring. Rebinding support means changing only that one file.
- **HUD uses legacy uGUI `Text`** to avoid the TextMeshPro essentials import
  prompt. Worth moving to TMP once art direction is settled.
- **Enemies are pooled** by `WaveManager`; `Health` resets in `OnEnable` so
  recycled instances come back at full HP. Anything else an archetype remembers
  across a life — a revenant's one revive, for instance — has to reset there too.
- **Per-instance materials for hit flash.** The GPU Resident Drawer ignores
  `MaterialPropertyBlock`, so `HitFlash` instances the material instead.
